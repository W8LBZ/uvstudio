**En bref :** une compression audio qui réduit le souffle. Les deux radios doivent l’activer pour que le son soit correct.

- **OFF** : normal. À garder sauf si vous savez que l’autre station utilise un compandeur.
- **TX** : compresse ce que vous envoyez.
- **RX** : décompresse ce que vous entendez.
- **TX/RX** : les deux. Bien entre deux radios réglées de la même façon.
- Si un seul côté l’utilise, le son « pompe » ou paraît étouffé.
- Non modifiable sur les VFO : la radio partage ce réglage entre les VFO A et B.
