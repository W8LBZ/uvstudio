**En bref :** de combien la fréquence change à chaque cran du bouton ou appui sur haut/bas.

- Choix courants : **12,5** ou **25** kHz pour la FM radioamateur, **8,33** kHz pour la bande aéro, **5** kHz pour l’exploration.
- La fréquence est arrondie à ce pas. Sur les VFO, avec un pas de 10 kHz ou plus, la radio utilise la moitié du pas : 12,5 kHz donne une grille de 6,25 kHz.
- Pour un canal mémoire fixe, cela compte surtout quand vous vous en écartez.
