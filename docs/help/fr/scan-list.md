**En bref :** le groupe auquel appartient ce canal lors d’un scan.

- Les listes **1 à 24** permettent de scanner seulement certains canaux, par exemple « relais locaux » ou « aéro ».
- **Toutes** : le canal est dans toutes les listes.
- **—** (aucune) : dans aucune liste, le scan par liste le saute.
- Les listes se renomment sous *Noms des listes de scan*.
- Pour garder un canal dans sa liste mais le sauter pour l’instant, utilisez [Ignorer](skip.md).
