> 💡 **En bref :** le DTMF, ce sont les tonalités des touches d’un téléphone. Les radioamateurs s’en servent pour commander des relais et envoyer de courts identifiants. Un débutant peut laisser cette partie de côté.

### D ST
Retour local : entendre les tonalités DTMF dans votre haut-parleur quand vous les envoyez.

### D Prel
Préchauffage : la durée d’émission avant le début des tonalités, pour que le récepteur soit prêt. Augmentez-la si le premier chiffre se perd.

### D Live
Affiche à l’écran les tonalités DTMF reçues.

### UPCode
Le code DTMF envoyé à l’appui sur PTT, sur les canaux dont le PTT ID vaut **UP** ou **UP+DOWN**.

### DWCode
Le code DTMF envoyé au relâchement de PTT, sur les canaux dont le PTT ID vaut **DOWN** ou **UP+DOWN**.
