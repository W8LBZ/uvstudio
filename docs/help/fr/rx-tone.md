**En bref :** un filtre pour votre propre haut-parleur. La radio reste muette tant qu’elle n’entend pas un signal portant ce code.

- Rien n’est envoyé, et les relais n’en tiennent pas compte. Seul ce que *vous* entendez change.
- **Vide** (le plus courant) : vous entendez tout ce qui passe sur la fréquence.
- **Renseignée** : vous n’entendez que les stations qui envoient ce code. Les autres utilisateurs de la fréquence restent silencieux.
- Beaucoup de relais renvoient leur tonalité : mettre la même valeur que la [tonalité TX](tx-tone.md) permet de n’entendre que ce relais.
- Si un canal qui devrait être actif reste muet, essayez d’abord de vider la tonalité RX.
- Mêmes formats que la tonalité TX : `88.5` pour le CTCSS, `D023N` / `D023I` pour le DCS.
