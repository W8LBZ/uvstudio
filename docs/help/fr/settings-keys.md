**En bref :** sons des touches, rôle des boutons latéraux et verrouillage du clavier.

### Beep
Bip à chaque appui sur une touche.

### F1Shrt
Action d’un appui court sur le bouton latéral 1 (celui du haut). Choix courants : **MONITOR** (ouvre le squelch pour entendre les signaux faibles), **FLASHLIGHT**, **SCAN**.

### F1Long
Action d’un appui long sur le bouton latéral 1.

### F2Shrt
Action d’un appui court sur le bouton latéral 2 (celui du bas).

### F2Long
Action d’un appui long sur le bouton latéral 2.

### M Long
Action d’un appui long sur la touche **MENU**.

### KeyLck
Verrouille le clavier automatiquement après cette durée sans appui. **OFF** ne verrouille jamais seul.

### SetLck
Ce que bloque le verrouillage : seulement les touches, les touches et les actions des boutons latéraux, les touches et PTT, ou tout.

### SetPTT
**CLASSIC** : maintenez PTT pour parler. **ONEPUSH** : un appui lance l’émission, un second l’arrête. Pratique pour parler longtemps, mais facile à oublier en émission.

### SetNav
Les flèches qui servent à naviguer dans les menus. Suivez votre radio : **LEFT/RIGHT** sur l’UV-K1, **UP/DOWN** sur l’UV-K5.

### SetKey
Éditions RescueOps uniquement : la touche à maintenir avec PTT à l’allumage pour entrer en mode Rescue Ops.
