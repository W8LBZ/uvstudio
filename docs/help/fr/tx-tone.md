**En bref :** un code inaudible envoyé avec votre voix. Beaucoup de relais vous ignorent si vous n’envoyez pas le bon.

- Si la fiche d’un relais indique une tonalité « CTCSS » ou « subaudible », mettez-la ici (par exemple `88.5`).
- **Vide** : aucune tonalité envoyée.
- **Un nombre comme `88.5`** : CTCSS, une tonalité grave en Hz.
- **Un code comme `D023N`** : DCS, un code numérique. **N** pour normal, **I** pour inversé. Suivez la fiche.
- La plupart du temps, seule la tonalité TX est nécessaire. La [tonalité RX](rx-tone.md) est facultative.
