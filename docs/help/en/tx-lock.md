> 💡 **TL;DR:** Should this channel or VFO follow the radio's transmit rulebook (the **F Lock** setting)? It doesn't turn transmitting off.

- **F Lock** is one rulebook for the whole radio: the band plan that says where it may transmit. There's only one, and it isn't set per channel.
- **TX lock** is a switch on each channel and each VFO that decides whether that one obeys the rulebook.
- **Checked (default)**: the radio refuses to transmit outside the F Lock plan. Inside the plan, it makes no difference. Leave it on.
- **Unchecked**: this channel or VFO ignores F Lock and can transmit anywhere the hardware can.
- Unchecking doesn't make transmitting legal. You're responsible for using only frequencies your license (or the service rules) allow.
