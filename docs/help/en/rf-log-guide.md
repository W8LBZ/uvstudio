**TL;DR:** The radio keeps a history of recent receive and transmit activity. This exports it as a CSV file you can open in a spreadsheet.

- Keep the radio in normal mode and press **Export RF Log**.
- Up to the latest 512 activities are read, with markers for each power-on.
- RF Log must be enabled in the firmware. If nothing comes back, check the radio's settings.
- For a live view while the radio is connected, use **RF Log** under UV Viewer.
