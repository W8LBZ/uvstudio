> 💡 **TL;DR:** Audio compression that cuts hiss. Both radios need it on for it to sound right.

- **OFF**: normal. Use this unless you know the other side uses a compander.
- **TX**: compress what you send.
- **RX**: expand what you hear.
- **TX/RX**: both. Good between two radios that are both set this way.
- With only one side using it, audio sounds pumping or muffled.
- Not editable on VFOs: the radio shares this setting between VFO A and B.

Read more: [Companding](https://en.wikipedia.org/wiki/Companding)
