> 💡 **TL;DR:** An inaudible code sent along with your voice. Many repeaters ignore you unless you send the right one.

- If a repeater's listing shows a "PL", "CTCSS" or "tone" value, put it here (for example `88.5`).
- **Blank**: no tone sent.
- **A number like `88.5`**: CTCSS, a low tone in Hz.
- **A code like `D023N`**: DCS, a digital code. **N** is normal and **I** is inverted. Use whatever the listing says.
- Most of the time you only need a TX tone. [RX tone](rx-tone.md) is optional.
