> 💡 **TL;DR:** Read the radio's menu settings, change them here, then write them back. Nothing reaches the radio until you press **Write changes to radio**.

### Read and write
- **Read from radio** loads the settings. The groups appear only after a read.
- Changed settings are highlighted and counted. **Write changes to radio** sends only those, then restarts the radio.
- The names are the radio's own menu names, so what you see here matches the radio's MENU.

### Backups (.bin)
- **Save backup (.bin)** keeps a copy of every setting. **Open backup (.bin)** loads one; press Write to put it on the radio.
- A backup never restores the radio's lock key or firmware version stamp, so it's safe to load onto another radio of the same model.

### What each group covers
Click a setting name for its help. Click a group title to fold or unfold the group; your choice is remembered, and **FM radio** starts folded.
- [Radio](settings-radio.md): squelch, receive modes, battery saver, audio.
- [Display](settings-display.md): screen, backlight, power-on message.
- [Keys](settings-keys.md): side buttons, key lock, PTT style.
- [Scan](settings-scan.md): which channels scan, priority channels, what happens on a signal.
- [Transmit](settings-tx.md): USER power, transmit alerts and timers.
- [DTMF](settings-dtmf.md): keypad tones for repeater control and IDs.
- [FM radio](settings-fm.md): broadcast FM band and saved stations.

### Not shown here
Some menus are left out on purpose: battery calibration, volume calibration and a few others that are risky or live elsewhere on the radio. Change those on the radio itself if you really need to.
