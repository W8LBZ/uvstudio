> 💡 **TL;DR:** Power level for USER channels, and transmit timers and alerts.

### SetPwr
The power a channel uses when its Power is set to **USER**. Change it here (or in the radio menu) and every USER channel follows.

### SetTOT
How the radio warns you when the transmit time-out (**TxTOut**) is about to stop you: a sound, a screen alert, both (**ALL**) or nothing.

### SetEOT
An alert when a transmission ends: a sound, a screen alert, both or nothing.

### SetTmr
Show a timer on screen while receiving or transmitting, so you can see how long you've been talking.

### SetOff
Put the radio into deep sleep after this long without use, to save the battery. **OFF** never sleeps.
