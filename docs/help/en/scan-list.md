**TL;DR:** Which group this channel belongs to when the radio scans.

- Lists **1–24** let you scan only a set of channels, such as "local repeaters" or "airband".
- **All**: the channel is in every list.
- **—** (none): not in any list, so list scans pass it by.
- You can rename lists under *Scan list names*.
- To leave a channel in its list but skip it for now, use [Skip](skip.md).

Read more: [CHIRP: memory editor columns](https://chirpmyradio.com/projects/chirp/wiki/MemoryEditorColumns)
