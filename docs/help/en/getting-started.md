> 💡 **TL;DR:** Back up first, change a little at a time, and write only when you're happy. You can always restore a backup.

### 1. Connect
Use a USB programming cable that carries data. Switch the radio on normally, then press **Read from radio** on any page and pick the radio's serial port.

### 2. Back up
- **Calibration**: back it up once and keep the file forever. See [Calibration](calibration-guide.md).
- **Memories** and **Radio settings**: after reading, press **Save backup (.bin)** on each page.

### 3. Add channels
On **Memories**, type a frequency into an empty row (turn on **Show empty channels**), or import a CSV list from your club or RepeaterBook. For a repeater, see [Repeaters](repeaters.md).

### 4. Write
Press **Write changes to radio**. Only changed channels are sent, and the radio restarts.

### 5. Try it
Listen on your new channels. If something sounds wrong, check [Squelch and tones](squelch-and-tones.md), or open your backup and write it back.

Before you transmit, read [Bands and licensing](bands-and-licensing.md).
