**TL;DR:** An inaudible code sent with your voice. Many repeaters ignore you unless you send the right one.

- **TX tone**: the code you *send*. If a repeater lists a "PL" or "CTCSS" tone, put it here (for example `88.5`).
- **RX tone**: the code you *require* before your speaker opens. It keeps other users' chatter on the same frequency quiet. Leave it blank to hear everything.
- **Blank**: no tone.
- **A number like `88.5`**: CTCSS, a low tone in Hz.
- **A code like `D023N`**: DCS, a digital code. **N** is normal and **I** is inverted. Use whatever the listing says.

A common setup is a TX tone only: the repeater hears you, and you hear everyone.
