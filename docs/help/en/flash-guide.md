**TL;DR:** Installs new firmware (the radio's operating software) on the radio. Back up your calibration first (see [Calibration](calibration-guide.md)).

### Before you start
- Save a calibration backup while the radio still works normally.
- Use a USB programming cable that carries data, not a charge-only cable.
- Put the radio in **DFU mode** (flash mode): with the radio off, hold **PTT** while switching it on. The screen stays blank.

### Flashing
- Pick an official F4HWN release from the list, or load a firmware file (.bin) from your computer.
- Press **Flash firmware** and choose the radio's serial port.
- Don't unplug the cable or switch the radio off until the progress bar finishes. The radio restarts with the new firmware.

### Editions
F4HWN comes in several editions. **Fusion** is the everyday one. **Transfer**, **FieldOps** and **Labs** add features for specific uses, and **Labs** is experimental. If you aren't sure, choose Fusion.

### CHIRP driver
The download link gives the CHIRP driver that matches this firmware, if you also use CHIRP on a computer.
