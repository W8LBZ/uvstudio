**TL;DR:** The radio's "free tuning" frequencies, one pair (A and B) per band, as opposed to stored memory channels.

- A VFO is what you see in frequency mode when you type or tune a frequency.
- The radio remembers the last VFO frequency and settings for each band. These rows let you set them directly.
- A VFO frequency must stay inside its band. To keep a frequency for good, store it in a memory channel.

Read more: [Variable-frequency oscillator](https://en.wikipedia.org/wiki/Variable-frequency_oscillator)
