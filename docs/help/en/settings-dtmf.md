**TL;DR:** DTMF is the keypad tones you hear on a phone. Hams use them to control repeaters and to send short IDs. Most beginners can leave this alone.

### D ST
Sidetone: hear the DTMF tones in your own speaker while you send them.

### D Prel
Preload: how long the radio transmits before the tones start, so the receiving side is ready. Raise it if the first digit gets lost.

### D Live
Show DTMF tones on screen as they're received.

### UPCode
The DTMF code sent when you press PTT on channels with PTT ID set to **UP** or **UP+DOWN**.

### DWCode
The DTMF code sent when you release PTT on channels with PTT ID set to **DOWN** or **UP+DOWN**.
